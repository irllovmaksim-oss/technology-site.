# AspanAir

Веб-сайт для поиска авиабилетов, отелей и туров.

## Возможности
- Главная страница
- Страница «О нас»
- Форма обратной связи
- Сохранение сообщений в SQLite
- Вход администратора
- Просмотр обращений
- Диагностика PHP и SQLite

## Технологии
- HTML
- CSS
- JavaScript
- PHP
- SQLite
- XAMPP

## Запуск
1. Поместить проект в папку htdocs.
2. Запустить Apache в XAMPP.
3. Открыть http://localhost/technology-site.-main/
